# مشروع إنشاء صفحة HTML

## فكرة المشروع
إنشاء صفحة ويب عربية تجريبية بعنوان **بوابة التعلم الرقمي**، تعرض تعريفًا بالبوابة
ومجموعة من المساقات وقسمًا للتواصل.

## ملفات المشروع
- `index.html`: الملف الرئيسي الذي يحتوي على هيكل الصفحة ومحتواها وتنسيقات CSS.

## شرح أجزاء الكود
1. `<!DOCTYPE html>` يحدد أن المستند يستخدم HTML5.
2. `<html lang="ar" dir="rtl">` يحدد لغة الصفحة العربية واتجاه الكتابة من اليمين إلى اليسار.
3. `<head>` يحتوي على بيانات الصفحة وإعدادات العرض والعنوان والتنسيقات.
4. `meta charset` يحدد ترميز UTF-8 لدعم الحروف العربية.
5. `meta viewport` يجعل عرض الصفحة مناسبًا للهواتف والشاشات المختلفة.
6. `<style>` يحتوي على قواعد CSS الخاصة بالألوان والمسافات والبطاقات وتنسيق الصفحة.
7. `<header>` يمثل رأس الصفحة ويحتوي على اسم الموقع.
8. `<nav>` يحتوي على روابط التنقل إلى أقسام الصفحة.
9. `<main>` يضم المحتوى الرئيسي.
10. `<section>` يقسم المحتوى إلى أقسام مستقلة.
11. `<article>` يستخدم لعرض كل مساق داخل بطاقة مستقلة.
12. `<a>` ينشئ رابطًا داخليًا للتنقل بين الأقسام.
13. `<footer>` يمثل تذييل الصفحة.

## ملاحظات
- تمت إضافة تعليقات HTML لتوضيح وظيفة كل جزء.
- تم استخدام CSS داخل ملف `index.html` لتنسيق الصفحة.
- يمكن فتح الملف مباشرة باستخدام أي متصفح إنترنت.

## طريقة التشغيل
افتح ملف `index.html` في متصفح مثل Google Chrome.

## الرفع إلى GitHub
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع الملفين `index.html` و`README.md`.
3. تأكد أن اسم ملف الصفحة هو `index.html`.
4. انسخ رابط المستودع وأرسله إلى الدكتور.
